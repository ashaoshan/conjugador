# Conjugador de Verbos en Español

Este proyecto es una app web hecha con Next.js + React que utiliza la API de OpenAI (ChatGPT) para conjugar verbos en español.

## Cómo usar

1. Descomprime el proyecto.
2. Crea un archivo `.env.local` en la raíz y añade tu clave de OpenAI:

```
OPENAI_API_KEY=tu_clave_aquí
```

3. Instala las dependencias:

```
npm install
```

4. Ejecuta el servidor:

```
npm run dev
```

5. Abre tu navegador en [http://localhost:3000](http://localhost:3000)

También puedes subirlo a GitHub y desplegarlo en Vercel fácilmente.
